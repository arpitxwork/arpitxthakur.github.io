# Arpit Thakur — Portfolio Foundation

A from-scratch HTML/CSS/JavaScript foundation for the personal portfolio.

## Files
- `index.html` — semantic page structure and hero
- `styles.css` — warm-yellow palette, typography, responsive layout, CSS-built diary
- `script.js` — small navigation interaction

## Run locally
Open `index.html` in a browser. Google Fonts load over the internet; system fallbacks are included.

## Publish on GitHub Pages
Upload the three site files to the root of a GitHub repository, enable Pages from the main branch and root folder, then open the published URL.

## Current scope
This is the first foundation only. Project case studies and creative assets are intentionally not included yet.


Sections in this version: About, Replica Rack project case study, Brand Worlds, and Creative Archives & Inspiration. The approved hero and header navigation markup are preserved; header links are not expanded in this pass.
